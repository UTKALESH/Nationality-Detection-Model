

# Nationality Detection and Emotion Analysis Model

## Description

This project develops a machine learning model that predicts:

- **Nationality** of a person based on their uploaded image.
- **Emotion** of the person (for all nationalities).

Depending on the predicted nationality:
- **Indian**: Predict Emotion + Age + Dress Color
- **United States**: Predict Emotion + Age
- **African**: Predict Emotion + Dress Color
- **Other Nationalities**: Predict Emotion + Nationality only

A **Graphical User Interface (GUI)** allows users to:
- Upload and preview an image.
- View the predicted outputs clearly.
